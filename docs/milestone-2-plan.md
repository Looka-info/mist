# Mist Platform — Milestone 2 Implementation Plan
**Native H.264 Hardware Decoding & Direct3D 11 Presentation**

## 1. Overview & Objectives

Milestone 2 establishes the native client video consumption pipeline for the Mist game streaming platform. The client must ingest real H.264 elementary streams generated by the host (Milestone 1), execute hardware-accelerated video decoding on the GPU without CPU readbacks, and present decoded frames through Direct3D 11 flip-model swap chains with minimal presentation jitter.

### Core Targets
- **Bitstream Ingestion:** Robust Annex-B H.264 parsing, NAL unit extraction, SPS/PPS caching, and access unit framing.
- **Hardware Decoding:** Zero-copy GPU-resident decoding utilizing Direct3D 11 Video infrastructure on the client's `ID3D11Device`.
- **Presentation Engine:** Direct3D 11 renderer using `DXGI_SWAP_EFFECT_FLIP_DISCARD`, aspect-ratio preserving letterboxing, and resize handling.
- **Presentation Timing:** Monotonic frame scheduling, queue bounding (max 2 frames), and drop-oldest policy when the renderer falls behind.
- **Diagnostics & Telemetry:** Full client CLI diagnostics (`--decoder-info`, `--decode-test`, `--present-test`, `--decode-benchmark`), latency histograms (p50/p95/p99), and JSON report emission.

## 2. Technical Decisions & Architecture (ADR Previews)

### ADR 0008: Hardware Video Decoder Selection
- **Evaluated:** (A) NVIDIA NVDEC (`nvcuvid.dll`) vs. (B) Direct3D 11 Hardware Video Decoder (D3D11 Video / MFT with `IMFDXGIDeviceManager`).
- **Decision:** Direct3D 11 Hardware Video Decoder.
  - *Multi-Vendor Portability:* Client devices frequently feature non-NVIDIA GPUs (Intel iGPUs, AMD APUs). D3D11 Video provides universal hardware decoding across NVIDIA, AMD, and Intel.
  - *Zero Inter-API Copies:* Decodes directly into native `ID3D11Texture2D` NV12 surfaces on the client's Direct3D 11 device, completely eliminating CUDA-to-DirectX interop and memory copies.
  - *Unified Device Ownership:* One `ID3D11Device` for decoding and presentation.

### ADR 0009: Decoded Frame Presentation Engine
- **Swap Chain Model:** DXGI Flip-Model (`DXGI_SWAP_EFFECT_FLIP_DISCARD`) for minimal presentation latency and desktop composition efficiency.
- **Color Conversion / Presentation:** Direct3D 11 Video Processor or Pixel Shader converting NV12 decoded frames to the RGB backbuffer with aspect ratio preservation and black letterboxing.
- **Queue Synchronization:** Bounded decoded frame queue (maximum 2 pending frames). Latency-first policy: drop obsolete presentation frames if the display refresh falls behind.

## 3. Subsystem Breakdown & Deliverables

### `engine/decode`
- `include/mist/decode/H264Parser.h` & `src/H264Parser.cpp`: Annex-B start-code parser, NAL unit validation, SPS/PPS/IDR metadata extraction, access unit builder.
- `include/mist/decode/AnnexBReader.h` & `src/AnnexBReader.cpp`: Stream reader for offline testing and bitstream validation.
- `include/mist/decode/D3D11VideoDecoder.h` & `src/D3D11VideoDecoder.cpp`: Hardware decoder implementing `IVideoDecoder`. Manages D3D11 device binding, MF DXGI device manager, and GPU-resident surface acquisition.

### `engine/render`
- `include/mist/render/D3D11Renderer.h` & `src/D3D11Renderer.cpp`: Renderer implementing `IRenderer`. Native Win32 window creation, DXGI flip swapchain, fullscreen toggle, resize handling, and headless rendering fallback.
- `include/mist/render/PresentationScheduler.h` & `src/PresentationScheduler.cpp`: Monotonic frame pacing, latency measurement, and drop policy.

### `apps/client`
- Diagnostic commands:
  - `--decoder-info`: Hardware decoder capabilities and profile query.
  - `--decode-test --input <file> [--headless] [--fps N] [--duration N]`: Runs decoding on an input bitstream.
  - `--present-test [--width W] [--height H] [--fps N]`: Validates presentation engine and swap chain.
  - `--decode-benchmark --input <file> --report <file>`: Emits machine-readable benchmark JSON.

### Tests & Verification
- `tests/unit/TestH264Parser.cpp`: NAL parsing, truncation, malformed bytes, bounds checks.
- `tests/unit/TestDecoder.cpp`: Hardware decoder initialization, access unit decoding, bitstream recovery.
- `tests/unit/TestRenderer.cpp`: Presentation engine, swapchain initialization, resize handling, frame queues.
- `tests/unit/TestClientStability.cpp`: Continuous decoding, repeated session restarts, headless stress runs.
- `scripts/verify-milestone-2.ps1`: End-to-end automated build, test, and benchmark verification script.
