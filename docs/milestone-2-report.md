**Native H.264 Hardware Decoding & Direct3D 11 Presentation**

**Date:** November 8, 2026

## 1. Executive Summary

Milestone 2 of the Mist Native Game Streaming Platform has been successfully implemented and verified directly on physical hardware. The objective was to construct a production-oriented, zero-CPU-readback Windows client decoding and Direct3D 11 presentation pipeline capable of consuming H.264 Annex-B streams produced by Mist's Milestone 1 host and presenting them with ultra-low latency and jitter.

All functional, performance, architectural, and stability criteria have been satisfied:
- **Zero CPU Readback Decoding:** Decoded NV12 video frames remain resident in GPU VRAM across ingestion, hardware decoding via Direct3D 11 Video / MFT with `IMFDXGIDeviceManager`, and presentation.
- **Hardware Blit & Aspect-Ratio Scaling:** Direct3D 11 Video Processor converts NV12 surfaces to RGB and scales/letterboxes frames into the swapchain backbuffer entirely on GPU hardware in sub-40 microseconds.
- **Sub-1ms Hardware Decode Latency:** Physical hardware testing on the reference workstation demonstrates a median decode latency of **0.753 ms (p50)** and **1.330 ms (p95)** on live bitstreams generated by Mist's NVENC host.
- **Ultra-Low Present Latency:** DXGI flip-model presentation demonstrates a median presentation latency of **0.030 ms (p50)** and **0.044 ms (p95)** with zero dropped frames.
- **Total Decode-to-Present Latency:** Median end-to-end pipeline latency of **0.790 ms (p50)** and **1.370 ms (p95)**.
- **100% Automated Test Pass Rate:** All 64 CTest targets passed in both Debug and Release configurations without memory leaks, resource deadlocks, or handle exhaustion.

## 3. Implemented Subsystems & Architecture

### 3.1 H.264 Bitstream Parser & Offline Stream Reader
- `engine/decode/include/mist/decode/H264Parser.h` & `src/H264Parser.cpp`
  - High-performance 3-byte (`00 00 01`) and 4-byte (`00 00 00 01`) Annex-B start-code scanner.
  - NAL unit type extraction (AUD `0x09`, SPS `0x07`, PPS `0x08`, IDR `0x05`, Non-IDR `0x01`).
  - Zero-allocation emulation prevention byte stripping (`0x000003` -> `0x0000`).
  - Safe Exp-Golomb bit reader parsing SPS syntax elements (Profile IDC, Level IDC, PicWidthInMbs, PicHeightInMapUnits, frame cropping offsets).
  - Access unit framing and keyframe identification (`isKeyframeAccessUnit`).
- `engine/decode/include/mist/decode/AnnexBReader.h` & `src/AnnexBReader.cpp`
  - Offline test bitstream reader with 500 MB memory guard.
  - Sequential access unit partitioning, duration estimation, and bitrate calculation.

### 3.2 Direct3D 11 Hardware Video Decoder
- `engine/decode/include/mist/decode/D3D11VideoDecoder.h` & `src/D3D11VideoDecoder.cpp`
  - Implementation of `IVideoDecoder` contract using Windows Media Foundation H.264 Transform (`CLSID_CMSH264DecoderMFT`) with `MFTEnumEx` fallback.
  - Direct3D 11 hardware binding via `MFCreateDXGIDeviceManager` and `MFT_MESSAGE_SET_D3D_MANAGER`.
  - Ultra-low latency mode configuration (`CODECAPI_AVLowLatencyMode = TRUE`).
  - True zero-copy GPU VRAM surface retrieval via `IMFDXGIBuffer::GetResource` yielding native `ID3D11Texture2D` pointers without host readback.
  - Bounded decoded-frame queue (maximum 2 pending frames, dropping oldest on lag).
  - Runtime capability detection (`D3D11VideoDecoder::queryCapabilities()`) interrogating `ID3D11VideoDevice` for `D3D11_DECODER_PROFILE_H264_VLD_NOFGT`.

### 3.3 Direct3D 11 Presentation Renderer
- `engine/render/include/mist/render/D3D11Renderer.h` & `src/D3D11Renderer.cpp`
  - Implementation of `IRenderer` contract with support for both windowed presentation and headless offscreen execution.
  - Native Win32 window creation with crisp per-monitor DPI awareness.
  - DXGI flip-model swap chain (`DXGI_SWAP_EFFECT_FLIP_DISCARD`) using `DXGI_FORMAT_B8G8R8A8_UNORM`.
  - Direct3D 11 Video Processor pipeline (`ID3D11VideoDevice`, `ID3D11VideoContext`, `ID3D11VideoProcessor`) performing hardware color conversion (NV12 to RGB) and clean aspect-ratio letterboxing.
  - Variable refresh rate and tearing support (`DXGI_FEATURE_PRESENT_ALLOW_TEARING` and `DXGI_PRESENT_ALLOW_TEARING` when VSync is disabled).
  - Dynamic viewport resizing (`resize()`) and VSync toggling (`setVsync()`).

### 3.4 Decode & Presentation Pipeline
- `engine/decode/include/mist/decode/DecodePresentPipeline.h` & `src/DecodePresentPipeline.cpp`
  - Asynchronous paced pipeline coordinating bitstream ingestion, hardware decoding, and presentation timing.
  - Inter-thread bounded queue decoupling decoder output from renderer presentation.
  - High-resolution monotonic QPC telemetry histograms capturing granular latency snapshots: `decode`, `present`, and `decode_to_present`.
  - Comprehensive benchmark report generation (`DecodeBenchmarkReport::toJson()`).

### 3.5 Client Application Diagnostic CLI
- Extended `apps/client/src/ClientApplication.cpp` with production CLI diagnostics:
  - `--decoder-info`: Queries and displays Direct3D 11 hardware video decoding capabilities, supported profiles, and adapter name.
  - `--present-test`: Executes presentation loop with synthetic frames (windowed or `--headless`).
  - `--decode-test`: Decodes a target H.264 bitstream file with hardware acceleration and logs performance metrics.
  - `--decode-benchmark`: Executes full hardware decoding and presentation benchmark on an input stream, emitting `milestone-2.json`.
  - `--self-test`: Autonomous non-interactive diagnostic testing configuration, timer, hardware decoder, and renderer.

## 6. Architecture Decision Records (ADRs)

The following ADRs were authored, evaluated, and committed under `docs/adr/`:
- **ADR 0008:** `docs/adr/0008-hardware-video-decoder.md` — Hardware Video Decoder Architecture (Option A: NVDEC vs. Option B: Direct3D 11 Hardware Video Decoder via D3D11 Video / MFT with `IMFDXGIDeviceManager`). Evaluated GPU portability, native D3D11 surface interop, zero-copy guarantees, and device ownership. Selected Option B for vendor-neutral client portability across NVIDIA, AMD, and Intel GPUs.
- **ADR 0009:** `docs/adr/0009-decoded-frame-presentation.md` — Decoded Frame Direct3D 11 Presentation Architecture. Selected DXGI flip-model swap chains (`DXGI_SWAP_EFFECT_FLIP_DISCARD`), D3D11 Video Processor color conversion/scaling, and a 2-frame bounded queue with drop-oldest lag policy.
