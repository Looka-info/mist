## Highlights & Milestone 27 Engineering Fixes

Mist v0.3.0-rc2 resolves all placeholder implementations and qualification gaps identified in the Milestone 26 audit:

1. **Real macOS Apple VideoToolbox Decoding:**
   - Replaced synthetic frame generation with genuine `VTDecompressionSessionCreate`.
   - SPS and PPS parameter set extraction from Annex-B H.264/HEVC bitstreams using `CMVideoFormatDescriptionCreateFromH264ParameterSets`.
   - Native sample buffer wrapping via `CMBlockBufferCreateWithMemoryBlock` and `CMSampleBufferCreateReady`.
   - Hardware decompression callback receiving real `CVPixelBufferRef` image buffers with dimensions, timestamps, and ARC/CFRelease lifecycle management.
   - Clean synchronization via `VTDecompressionSessionWaitForAsynchronousFrames` and teardown with `VTDecompressionSessionInvalidate`.

2. **Real Linux VA-API Decoding:**
   - Replaced mock integer surface identifiers with actual DRM render node initialization (`/dev/dri/renderD128`, falling back to `/dev/dri/card0`).
   - Driver context initialization via `vaGetDisplayDRM` and `vaInitialize`.
   - Codec profile queries via `vaQueryConfigProfiles`, validating H.264, HEVC, and AV1 support.
   - Genuine `VASurfaceID` ring buffer allocation via `vaCreateSurfaces` and context creation via `vaCreateContext`.
   - Slice parameter submission via `vaCreateBuffer`, `vaBeginPicture`, `vaRenderPicture`, and `vaEndPicture`.
   - Hardware presentation synchronization via `vaSyncSurface`.

3. **Real Android NDK AMediaCodec Decoding:**
   - Implemented native `AMediaCodec_createDecoderByType` for MIME types `video/avc`, `video/hevc`, and `video/av01`.
   - Format configuration via `AMediaFormat_new`, setting dimensions and codec parameters.
   - Surface attachment via `ANativeWindow` and decoder startup via `AMediaCodec_start`.
   - Non-blocking input buffer dequeue (`AMediaCodec_dequeueInputBuffer`), NAL unit copying, and presentation queuing (`AMediaCodec_queueInputBuffer`).
   - Output buffer handling with `AMediaCodec_dequeueOutputBuffer` and rendering via `AMediaCodec_releaseOutputBuffer`.

4. **Accurate Runtime Decoder Capability Reporting:**
   - Replaced hardcoded compile-time macro `"Production Qualified"` strings with fine-grained runtime `DecoderQualificationState` states:
     - `NotSupported`
     - `NotBuilt`
     - `Built`
     - `NativeApiAvailable`
     - `HardwareAvailable`
     - `DecoderInitialized`
     - `SmokeTestPassed`
     - `HardwareVerified`
   - Dynamically probes DRM nodes, Direct3D 11 devices, and Apple/NDK runtime availability before claiming hardware acceleration.

5. **Real Browser WebRTC & WebCodecs Guest Streaming:**
   - Completely purged `startSimulationStream()` and synthetic random RTT math (`Math.random() * 2 + 1.5`) from production code.
   - Implemented real WebRTC `RTCPeerConnection` with STUN ICE servers.
   - Implemented WebSocket signaling integration with `mist-signaling` for registration, offer/answer SDP exchange, and ICE candidates.
   - Attached remote video streams to hardware-accelerated `<video id="remote-video">` element with Canvas fallback.
   - High-frequency low-latency input streaming over SCTP DataChannel (`mist-input`).
   - Real QoS telemetry collected via `pc.getStats()` (actual RTT, packet loss, frames decoded, FPS, jitter).

6. **Rust Toolchain & Cross-Platform CI Matrix Repair:**
   - Fixed `rust-toolchain.toml` channel from invalid `stable-x86_64-pc-windows-gnu` to standard `stable`.
   - Repaired `.github/workflows/ci.yml` matrix across Windows, macOS, Linux, Android NDK, and Web.
   - Excluded Windows-only desktop crates on Linux/macOS Cargo test jobs while testing all cross-platform crates.
   - Added headless browser qualification test suite (`web/test/run_browser_tests.js`).
