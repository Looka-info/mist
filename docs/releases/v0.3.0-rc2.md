## Highlights

Mist v0.3.0-rc2 closes all architectural and implementation gaps identified in the Milestone 26 audit, delivering genuine cross-platform decoder implementations, a real WebRTC web guest client, and an honest runtime capability model:

1. **Native Hardware Video Decoders:**
   - **macOS (Apple VideoToolbox):** Real `VTDecompressionSessionCreate`, SPS/PPS and VPS/SPS/PPS parameter set extraction (`CMVideoFormatDescriptionCreateFromH264ParameterSets` / `CMVideoFormatDescriptionCreateFromHEVCParameterSets`), `CMSampleBuffer` wrapping, and thread-safe decompression output callback handlers.
   - **Linux (VA-API / DRM):** Real DRM render node discovery (`/dev/dri/renderD128`, `/dev/dri/card0`), driver query, genuine `vaCreateSurfaces` allocation, and a bounded 4-surface pool with explicit lifecycle states (`Available`, `Decoding`, `Decoded`, `InUse`, `Released`).
   - **Android (NDK AMediaCodec):** Real `AMediaCodec_createDecoderByType`, `AMediaFormat`, `AMediaCodec_configure`, `AMediaCodec_start`, dequeue/queue buffer management, and presentation to `ANativeWindow`.
   - **Windows (D3D11VA):** Production-qualified zero-copy Direct3D 11 hardware decoding.

2. **Typed Runtime Decoder Qualification Model:**
   - Replaced compile-macro string assertions (`"Production Qualified"`) with a typed `DecoderQualificationState` enum containing 8 discrete lifecycle states:
     `NotSupported`, `NotBuilt`, `Built`, `NativeApiAvailable`, `HardwareAvailable`, `DecoderInitialized`, `SmokeTestPassed`, `HardwareVerified`.
   - Hardware verification is only granted after real GPU decode validation with bitstream fixtures on native hardware.

3. **Real WebRTC Web Guest Client:**
   - Completely eliminated synthetic simulation code (`startSimulationStream()`, fake canvas text animations, and random jitter math).
   - Standard W3C `RTCPeerConnection` connecting over WebSocket to `mist-signaling`.
   - Remote media tracks directly bound to `<video id="remote-video">` for hardware presentation.
   - Binary input dispatch over SCTP DataChannel with `0x4D495354` header.
   - Live telemetry powered by `pc.getStats()` (bitrate, packet loss, frames decoded, jitter).

4. **Integrated Guest Pipeline:**
   - `GuestClientSession` connected directly to native platform decoders.
   - Enforced bounded queue pacing (maximum 16 frames) with drop-oldest backpressure to eliminate frame latency under heavy load.
   - Full RAII resource lifetime management.

5. **Cross-Platform CI Matrix:**
   - Repaired `.github/workflows/ci.yml` across Windows 11 x64, macOS 14 (Apple Silicon), Ubuntu 22.04 (Linux), Android NDK r26b, and Web.
   - Added automated caching, VCPKG binary caching, and dependency isolation.

6. **Native Bitstream Test Fixtures:**
   - Added valid Annex-B test streams (`tests/fixtures/h264_baseline_720p.bin`, `hevc_main_720p.bin`, `av1_sequence_720p.bin`).
   - Added comprehensive native smoke and lifecycle tests in CTest.
