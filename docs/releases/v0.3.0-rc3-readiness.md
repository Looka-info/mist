## 3. Comparison: v0.3.0-rc2 vs v0.3.0-rc3

| Capability | v0.3.0-rc2 | v0.3.0-rc3 |
|:---|:---|:---|
| **VideoToolbox Shutdown** | Deadlock hazard on `VTDecompressionSessionWaitForAsynchronousFrames` while holding `mutex_`. | Reentrancy-safe; drops `mutex_` before waiting; atomic shutdown guard. |
| **VA-API Picture Buffers** | Empty stub buffer submits without parameter structures. | Implements parameter buffers (`VAPictureParameterBufferH264`, `VAIQMatrixBufferH264`, etc.). |
| **Android Buffer Index 0** | Condition `bufferIndex > 0` leaked index 0. | Condition `bufferIndex != UINT64_MAX` properly releases all valid buffer indices. |
| **Web Browser Signaling** | Race condition: candidate arrival prior to SDP offer threw `InvalidStateError`. | In-memory candidate queueing buffers candidates until `setRemoteDescription` completes. |
| **Browser Input Packets** | Flawed 20-byte invented header (`0x4D495354`). | Exact 48-byte native `InputPacketHeader` + packed C++ struct payloads. |
| **Linux Pairing Tests** | Hardcoded port 8099 caused `EADDRINUSE` in parallel CI runs. | Dynamic port 0 binding assigns ephemeral socket without collisions. |
| **CTest Test Count** | 230 tests. | **235 tests** (added 5 new cross-platform tests). |
