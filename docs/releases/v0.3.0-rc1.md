# Mist v0.3.0-rc1 Release Candidate Notes

**Release Date:** November 9, 2026  
**Target Architecture:** Windows 11 / 10 x64 (Host & Client), macOS, Linux, Android, Web (Guests)  
**Primary UI:** Slint 1.18.1 (Pixel Mint Material Design 3)  
**Native Engine:** C++20 Direct3D 11 / NVENC / WebRTC  

---

## Highlights

Mist v0.3.0-rc1 represents a major milestone in high-performance game streaming:
1. **Complete Rust-First Migration:**
   - Slint 1.18.1 native Windows application (`apps/mist-desktop`) with Material Design 3 Pixel Mint styling.
   - 0 mock controls, 100% wired into native Rust services and IPC channels.
2. **Next-Generation Video Pipeline:**
   - Hardware AV1, HEVC (H.265), and H.264 encoding and decoding.
   - SMPTE ST 2084 PQ EOTF and ACES/Reinhard HDR10 tone mapping.
   - Zero-copy Direct3D 11 Video Acceleration (D3D11VA) guest presentation.
   - AMD AMF, Intel QuickSync, and software x264/AV1 fallback cascades.
3. **Multi-Guest Fanout & QoS:**
   - Single-encode GPU fanout to multiple concurrent guests.
   - Slow-client isolation preventing network congestion on one guest from affecting others.
   - Per-guest adaptive bitrate tiers (1080p Quality, 1080p Balanced, 720p Performance).
   - Host aggregate uplink bandwidth manager with priority audio and control reservations.
4. **Cross-Platform Guest Clients:**
   - Unified `GuestClientSession` pipeline.
   - Windows (D3D11VA), macOS (Apple VideoToolbox), Linux (VA-API / DMA-BUF), Android (NDK AMediaCodec), Web (W3C WebCodecs).
   - Standalone browser client in `web/` using native WebCodecs and Pointer Lock API.
5. **Display & System Reliability:**
   - IddCx Virtual Display Driver manager with dynamic EDID 1.4 generation for headless host streaming.
   - Windows Session 0 host background service with system tray companion.
   - Wake-on-LAN magic packet dispatch.
   - Windows Graphics Capture (WGC) fallback for hybrid GPU laptops.
6. **Hardened Security & Pairing:**
   - FIPS 180-4 SHA-256 tokens, DTLS fingerprint binding, Short Authentication String (SAS).
   - Host approval flows (Deny, Kick, persistent Ban ledger).
   - Per-guest permission bitmasks (View-Only, Keyboard/Mouse, Gamepad, Clipboard, Audio).

## Known Platform Limitations

1. **Operating System Permissions:**
   - macOS requires accessibility permissions for synthetic input and screen recording permissions for host capture.
   - Linux Wayland requires xdg-desktop-portal / PipeWire for capture; VA-API requires user in `render` group.
   - Web requires HTTPS or localhost secure context for WebCodecs and user gesture for Pointer Lock.
2. **AV1 Hardware Encoding:**
   - Requires NVIDIA Ada Lovelace (RTX 40-series) or newer GPU; earlier GPUs fall back to HEVC/H.264 or CPU AV1.
